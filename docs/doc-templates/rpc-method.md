**Тип вызова:** <унарный | серверный поток | клиентский поток | двунаправленный поток>

### Пример

```cpp
<минимальный пример вызова>
```

## Пример заполнения

Ниже — описание метода `GetFile`, оформленное по шаблону.

### GetFile

Метод передаёт клиенту выбранный файл частями по 1 МиБ.

**Тип вызова:** серверный поток.

```cpp
grpc::ClientContext context;
FileRequest request;
request.set_name("weld_2026-11-19_001.png");
auto reader = stub->GetFile(&context, request);
FileReply chunk;
while (reader->Read(&chunk)) {
    output.write(chunk.data().data(), chunk.data().size());
}
grpc::Status status = reader->Finish();
```

Таблица 1 — Поля сообщения `FileRequest`

| Поле | Тип | Обязательное | Описание |
| --- | --- | --- | --- |
| `name` | `string` | Да | Имя файла без пути |

Таблица 2 — Поля сообщения `FileReply`

| Поле | Тип | Описание |
| --- | --- | --- |
| `data` | `bytes` | Очередная часть файла, не более 1 МиБ |

Таблица 3 — Коды статуса метода `GetFile`

| Код статуса | Условие | Действие клиента |
| --- | --- | --- |
| `NOT_FOUND` | Файла нет в хранилище | Сообщить оператору и обновить список |
| `INVALID_ARGUMENT` | Имя содержит путь | Сообщить о некорректном имени |
| `CANCELLED` | Загрузка отменена | Удалить неполный файл |
