# Шаблон инструкции оператора

Инструкция описывает одну задачу оператора. Для документа «Руководство
оператора» по ГОСТ 19.505–79 инструкции объединяются в раздел
«Выполнение программы».

````markdown
## <Задача в инфинитиве>

<Когда и зачем выполняется задача — одно предложение.>

**Перед началом:** <условия: клиент запущен, есть соединение и т. п.>

1. <Действие в повелительном наклонении.>
2. <Действие.>

    <Ожидаемый результат шага, если он неочевиден.>

3. <Действие.>

**Результат:** <что увидит оператор после выполнения.>

**Если что-то пошло не так:** <ссылка на раздел с ошибками.>
````

## Пример заполнения

### Загрузить файл с сервера

Загрузка нужна, чтобы получить снимок сварного шва на компьютер для анализа.

**Перед началом:** клиент FileTransfer подключён к серверу.

1. В поле «Дата начала» и «Дата окончания» укажите период съёмки.
2. Нажмите «Показать».

    В списке появятся файлы за выбранный период.

3. Выберите файл в списке и нажмите «Скачать».
4. Выберите папку для сохранения и нажмите «Сохранить».

**Результат:** индикатор загрузки дошёл до 100 %, файл сохранён в выбранной
папке.

**Если что-то пошло не так:** см. раздел
[Интерфейс и сообщения об ошибках](../content/ui-errors.md).
