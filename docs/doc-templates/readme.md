# Шаблон README компонента

Используйте шаблон для файлов `README.md` в каталогах `server/` и `client/`.
Скопируйте блок ниже и замените текст в угловых скобках.

````markdown
# <Название компонента>

<Одно-два предложения: что делает компонент и кому нужен.>

## Требования

- <ОС и версия>
- <Компилятор, Qt, gRPC — с версиями>

## Сборка

```bash
<команды сборки>
```

## Запуск

```bash
<команда запуска с заполнителями>
```

## Настройка

| Параметр | Значение по умолчанию | Описание |
| --- | --- | --- |
| `<--param>` | `<value>` | <описание> |

## Проверка работоспособности

<Как убедиться, что компонент работает: команда и ожидаемый результат.>

## Связанные документы

- [Описание gRPC-интерфейса](<путь>)
````

## Обязательные разделы

| Раздел | Обязателен | Комментарий |
| --- | --- | --- |
| Назначение (вводный абзац) | Да | СТ-1 |
| Требования | Да | Версии указывайте явно |
| Сборка | Да | Команды копируются без правок |
| Запуск | Да | — |
| Настройка | Если есть параметры | Таблица по СП-4 |
| Проверка работоспособности | Да | — |
| Связанные документы | Нет | — |
