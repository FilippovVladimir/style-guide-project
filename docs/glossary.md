# Глоссарий

Термины расположены по алфавиту: сначала русские, затем латинские.

Блок
:   Часть файла, передаваемая в одном сообщении `FileReply`. Размер блока —
    не более 1 МиБ.

<!-- terms-off -->

Загрузка файла
:   Передача файла с сервера на компьютер оператора. Синонимы «скачивание»,
    «скачка» не используются.

<!-- terms-on -->

Клиент
:   Приложение оператора на C++/Qt/QML, которое обращается к серверу по gRPC.

Оператор
:   Сотрудник, который получает и анализирует изображения с оборудования.

Отмена загрузки
:   Прекращение текущей загрузки по команде оператора.

Сервер
:   Программа на удалённом оборудовании, которая хранит изображения и
    обрабатывает запросы клиента.

Хранилище
:   Каталог на сервере, в котором находятся файлы изображений.

gRPC
:   Платформа удалённого вызова процедур, которая используется для обмена
    данными между клиентом и сервером.

Protocol Buffers (protobuf)
:   Формат описания и сериализации сообщений gRPC. Контракт хранится в файле
    `file_service.proto`.

Pull Request (PR)
:   Запрос на слияние изменений из ветки в `main` на GitHub.
