# Рисунки и ссылки

## РС-1. Подписи к рисункам

Под каждым рисунком — подпись «Рисунок N — Название» без точки в конце.
В тексте до рисунка на него есть ссылка: «Окно загрузки показано на
рисунке 2».

## РС-2. Альтернативный текст

У каждого изображения в Markdown заполнен альтернативный текст, который
описывает, что изображено, а не повторяет подпись.

```markdown
![Главное окно клиента: список файлов с датами и кнопки «Скачать» и «Удалить»](img/main-window.png)
```

## РС-3. Снимки экрана

- Формат — PNG, ширина — не более 1600 пикселей.
- Обрезайте снимок до нужной области окна.
- Личные данные, адреса серверов и реальные производственные изображения
  закрывайте или заменяйте тестовыми.
- Имена файлов — латиницей через дефис: `download-progress.png`.

## РС-4. Диаграммы

Диаграммы храните как код (Mermaid или PlantUML) рядом с документом, чтобы их
можно было изменять через Pull Request.

## РС-5. Ссылки

- Текст ссылки описывает, куда она ведёт: «см. [коды ошибок](../content/ui-errors.md)», а не
  «нажмите [здесь](../content/ui-errors.md)».
- Внутри документации используйте относительные ссылки на файлы `.md`.
- На внешние стандарты ссылайтесь с полным обозначением: «ГОСТ 19.505–79».
