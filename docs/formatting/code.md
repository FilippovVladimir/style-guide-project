# Код и идентификаторы

## КД-1. Встроенный код

Оформляйте как встроенный код (обратные апострофы) имена методов, классов,
файлов, каталогов, параметров, переменных окружения и значения:
`GetFile`, `FileServiceImpl`, `file_service.proto`, `CHUNK_SIZE`.

| Так | Не так |
| --- | --- |
| Метод `RemoveFile` удаляет файл. | Метод RemoveFile удаляет файл. |
| Укажите порт в параметре `--port`. | Укажите порт в параметре «--port». |

## КД-2. Блоки кода

- Всегда указывайте язык блока: `cpp`, `protobuf`, `bash`, `qml`, `text`.
- Команды для терминала пишите без символа приглашения `$`, чтобы их можно
  было скопировать.
- Длинный вывод сокращайте и обозначайте пропуск комментарием `# ...`.

```protobuf
service File {
  rpc NewFiles (FilesListRequest) returns (stream FileInfo);
  rpc GetFile (FileRequest) returns (stream FileReply);
  rpc RemoveFile (FileRequest) returns (google.protobuf.Empty);
}
```

## КД-3. Заполнители

Значения, которые читатель подставляет сам, пишите в угловых скобках
латиницей через дефис: `<server-address>`, `<file-name>`.

```bash
./client --server <server-address>:50051
```

## КД-4. Пример перед описанием параметров

В описании метода сначала приводите минимальный рабочий пример, затем
таблицу параметров. Пример должен компилироваться или выполняться без
изменений, кроме заполнителей.
