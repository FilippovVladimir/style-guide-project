# Списки и таблицы

## СП-1. Выбор вида списка

- Нумерованный список — для последовательных шагов, где важен порядок.
- Маркированный список — для перечислений, где порядок не важен.
- В Markdown маркер — дефис `-`.
- В одном списке — не менее двух и не более девяти пунктов.

## СП-2. Пунктуация в списках

- Если пункты — законченные предложения, начинайте их с прописной буквы
  и заканчивайте точкой.
- Если пункты — части одного предложения после двоеточия, начинайте их
  со строчной буквы и разделяйте точкой с запятой; после последнего пункта
  ставьте точку.

Пример второго варианта. Клиент позволяет:

- получить список файлов;
- загрузить выбранный файл;
- удалить файл на сервере.

## СП-3. Когда нужна таблица

Используйте таблицу, если у трёх и более объектов есть одинаковый набор
характеристик (например, параметры запроса: имя, тип, описание). Не
используйте таблицу для вёрстки текста.

## СП-4. Оформление таблиц

- Перед таблицей — подпись: «Таблица N — Название».
- Заголовки столбцов — с прописной буквы, без точки.
- Пустые ячейки не допускаются: ставьте «—».
- Столбец с идентификаторами или именами — первый.
