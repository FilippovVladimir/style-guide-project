# Тон и голос

## ТН-1. Нейтральный деловой тон

Пишите спокойно и по существу. Не используйте разговорные слова, шутки,
восклицательные знаки и эмодзи.

| Так | Не так |
| --- | --- |
| Сервер возвращает список файлов за указанный период. | Сервер шустро отдаёт список файлов! |
| Загрузка прервана: соединение с сервером потеряно. | Упс, что-то пошло не так 😢 |

## ТН-2. Обращение к читателю

В инструкциях обращайтесь к читателю на «вы» через повелительное наклонение
(«нажмите», «выберите»). Слово «вы» с маленькой буквы, используйте его только
когда без него фраза непонятна.

| Так | Не так |
| --- | --- |
| Выберите папку для сохранения. | Пользователю необходимо осуществить выбор папки. |
| Нажмите «Скачать». | Вы должны будете нажать на кнопку «Скачать». |

В описаниях архитектуры и отчётах пишите безлично или от лица системы:
«Сервер передаёт файл блоками по 1 МиБ».

## ТН-3. Без оценок и обещаний

Не оценивайте систему («удобный», «мощный», «быстрый») без измеримого
подтверждения. Если характеристика важна, приведите число.

| Так | Не так |
| --- | --- |
| Файл размером 100 МиБ передаётся за 12 с в локальной сети 1 Гбит/с. | Файлы передаются очень быстро. |

## ТН-4. Честность о статусе

Отличайте реализованное от планируемого. Для планов используйте слова
«планируется», «предлагается», для реализованного — настоящее время.

| Так | Не так |
| --- | --- |
| Отмена загрузки реализована на клиенте. Отмена на сервере планируется в версии 1.2. | Система поддерживает отмену загрузки. |
