# Язык и грамматика

## ЯЗ-1. Действительный залог и активные глаголы

Предпочитайте действительный залог страдательному: так понятно, кто выполняет
действие. Страдательный залог допустим, если исполнитель неважен.

| Так | Не так |
| --- | --- |
| Клиент отправляет запрос `GetFile`. | Запрос `GetFile` отправляется клиентом. |
| Сервер удаляет файл. | Производится удаление файла сервером. |

## ЯЗ-2. Без отглагольных существительных

Заменяйте конструкции «осуществление», «произведение», «выполнение действия»
глаголами.

| Так | Не так |
| --- | --- |
| Проверьте соединение. | Произведите проверку соединения. |
| Клиент сортирует файлы по дате. | Осуществляется сортировка файлов по дате. |

## ЯЗ-3. Длина предложения

Одно предложение — одна мысль. Ориентир — не более 25 слов. Если предложение
длиннее, разделите его или оформите перечисление списком.

## ЯЗ-4. Длина абзаца

Абзац — не более 5 предложений. В инструкциях один шаг — один абзац или один
пункт нумерованного списка.

## ЯЗ-5. Канцелярит и слова-паразиты

Удаляйте слова, которые не несут смысла: «данный», «является», «в целях»,
«в рамках», «осуществлять», «на сегодняшний день», «как правило» (если правило
не названо).

| Так | Не так |
| --- | --- |
| Метод возвращает имя файла. | Данный метод является методом, возвращающим имя файла. |
| Чтобы загрузить файл, … | В целях осуществления загрузки файла … |

## ЯЗ-6. Условие перед действием

В инструкциях сначала указывайте условие или цель, затем действие.

| Так | Не так |
| --- | --- |
| Чтобы отменить загрузку, нажмите «Отменить». | Нажмите «Отменить», чтобы отменить загрузку. |
| Если сервер недоступен, проверьте адрес в настройках. | Проверьте адрес в настройках, если сервер недоступен. |
