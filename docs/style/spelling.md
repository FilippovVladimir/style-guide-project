# Орфография и пунктуация

## ОП-1. Буква «ё»

Пишите «ё» везде, где она произносится: «объём», «удалённый», «передаёт».
Линтер терминов проверяет частые слова проекта.

## ОП-2. Кавычки

Основные кавычки — «ёлочки», вложенные — „лапки“. Прямые кавычки `"` допустимы
только внутри кода.

## ОП-3. Тире и дефис

- Тире (—) с пробелами с обеих сторон — между частями предложения:
  «Клиент — приложение оператора».
- Короткое тире (–) без пробелов — в диапазонах чисел: «10–20 файлов»,
  «2024–2026».
- Дефис (-) без пробелов — в составных словах: «клиент-серверный»,
  «gRPC-интерфейс».

## ОП-4. Неразрывный пробел

Ставьте неразрывный пробел между числом и единицей измерения, в сокращениях
«т. д.», «т. е.», перед тире и после знака «№».

## ОП-5. Точка в конце

- В заголовках, подписях к рисункам и таблицам точку не ставьте.
- В пунктах списка — по правилу СП-2.
- В ячейках таблиц точку ставьте, только если в ячейке несколько предложений.

## ОП-6. Сокращения

Не используйте сокращения, кроме общепринятых («т. е.», «и т. д.») и
перечисленных в глоссарии. Аббревиатуру при первом упоминании в документе
расшифруйте: «удалённый вызов процедур (RPC)».
