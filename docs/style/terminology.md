# Терминология

## ТР-1. Один термин — одно понятие

Используйте термины из [глоссария](../glossary.md). Не заменяйте термин
синонимом ради разнообразия текста: читатель решит, что речь идёт о другом
объекте.

## ТР-2. Предпочтительные и запрещённые варианты

<!-- terms-off -->

| Используйте | Не используйте |
| --- | --- |
| загрузка файла (с сервера на клиент) | скачка, скачивание, даунлоад |
| удаление файла | стирание, ремув |
| отмена загрузки | прерывание, стоп, абортирование |
| оператор | юзер, пользак |
| сервер | бэк, бэкенд (в документации для оператора) |
| клиент, клиентское приложение | фронт, морда |
| gRPC | GRPC, Grpc, грпц |
| Qt | QT, кьют |
| QML | Qml |
| Protocol Buffers, protobuf | протобаф |

<!-- terms-on -->

Слово «скачать» допустимо только как название кнопки интерфейса: «Скачать».

## ТР-3. Англоязычные термины

- Названия технологий, продуктов и стандартов пишите в оригинале: gRPC, Qt,
  GitHub, MkDocs.
- Не склоняйте названия технологий с помощью дефиса и окончаний:
  «в gRPC», а не «в gRPC-е».
<!-- terms-off -->

- Если существует устоявшийся русский термин, используйте его: «запрос»,
  а не «реквест»; «ветка», а не «бранч».

<!-- terms-on -->

## ТР-4. Названия компонентов проекта

| Компонент | Как писать в тексте |
| --- | --- |
| Сервис на сервере | сервер FileTransfer, gRPC-сервис `File` |
| Приложение оператора | клиент FileTransfer |
| Контракт | файл `file_service.proto` |
