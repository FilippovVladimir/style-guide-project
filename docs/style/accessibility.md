# Доступность текста

Правила раздела помогают сделать документацию понятной для всех читателей:
людей, которые используют программы экранного доступа, плохо различают цвета,
читают с мобильного устройства или не являются носителями русского языка.

## ДС-1. Простые слова и короткие предложения

Пишите общеупотребительными словами. Сложный термин поясняйте при первом
упоминании или давайте ссылку на глоссарий. Ориентир — не более 25 слов
в предложении (ЯЗ-3).

| Так | Не так |
| --- | --- |
| Сервер передаёт файл частями — блоками по 1 МиБ. | Осуществляется чанкированная передача бинарного контента. |

## ДС-2. Информация не только цветом

Не передавайте смысл только цветом или расположением. Дублируйте его текстом
или значком с подписью.

| Так | Не так |
| --- | --- |
| Файлы с ошибкой загрузки отмечены подписью «Ошибка». | Файлы с ошибкой выделены красным. |
| Нажмите «Удалить» в правом нижнем углу окна. | Нажмите красную кнопку справа. |

## ДС-3. Альтернативный текст изображений

У каждого изображения есть альтернативный текст (РС-2). Он описывает смысл
изображения в одном-двух предложениях. Декоративные изображения в
документацию не добавляйте.

Наличие альтернативного текста проверяется автоматически: линтер
markdownlint (правило MD045) не пропустит изображение без него.

| Так | Не так |
| --- | --- |
| `![Окно загрузки: индикатор на 45 %, кнопка «Отменить»](img/progress.png)` | `![image1](img/progress.png)` |

## ДС-4. Понятные ссылки

Текст ссылки понятен без окружающего текста: программы экранного доступа
часто зачитывают список ссылок отдельно (РС-5).

| Так | Не так |
| --- | --- |
| Подробнее — в разделе «Коды ошибок». | Подробнее — тут. |

## ДС-5. Структура для навигации

- Используйте заголовки по порядку уровней (СТ-2): по ним перемещаются
  программы экранного доступа.
- Оформляйте перечисления списками, а не строками через точку с запятой.
- У таблиц всегда есть строка заголовков.
- В документах Word не объединяйте ячейки таблиц: программы экранного
  доступа читают такие таблицы с ошибками. В Markdown объединение ячеек
  невозможно, поэтому для него правило выполняется автоматически.

## ДС-6. Код и команды как текст

Команды, фрагменты кода и сообщения об ошибках приводите текстом в блоке кода,
а не снимком экрана: текст можно скопировать, найти поиском и прочитать
программой экранного доступа.

## ДС-7. Без указаний на органы чувств и устройства

Описывайте действие, а не способ восприятия или устройство ввода.

| Так | Не так |
| --- | --- |
| Выберите файл в списке. | Кликните мышкой по файлу, который видите слева. |
| Когда загрузка завершится, появится сообщение «Файл сохранён». | Когда увидите зелёную галочку, загрузка завершена. |
