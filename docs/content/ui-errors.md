# Интерфейс и сообщения об ошибках

## ИН-1. Элементы интерфейса

Названия кнопок, пунктов меню, полей и окон пишите в «ёлочках» так, как они
написаны в интерфейсе, с сохранением регистра.

| Так | Не так |
| --- | --- |
| Нажмите «Скачать». | Нажмите кнопку **СКАЧАТЬ**. |
| В поле «Дата начала» укажите … | В поле дата начала укажите … |

Слово «кнопка» опускайте, если из контекста понятно, что это кнопка.

## ИН-2. Последовательность действий в меню

Путь по меню записывайте через стрелку «→»:
«Файл → Настройки → Сервер».

## ИН-3. Сообщения об ошибках в интерфейсе

Сообщение об ошибке отвечает на два вопроса: что произошло и что делать.

| Так | Не так |
| --- | --- |
| Файл не найден на сервере. Обновите список файлов. | Error 5 |
| Нет соединения с сервером. Проверьте адрес и повторите попытку. | Что-то пошло не так |

## ИН-4. Описание ошибок в документации

Ошибки gRPC-методов описывайте таблицей: код статуса, условие, действие
клиента.

Таблица 1 — Пример описания ошибок метода `GetFile`

| Код статуса | Условие | Действие клиента |
| --- | --- | --- |
| `NOT_FOUND` | Файл отсутствует в хранилище | Показать сообщение и обновить список |
| `INVALID_ARGUMENT` | Передан абсолютный путь или `..` | Показать сообщение о некорректном имени |
| `CANCELLED` | Оператор отменил загрузку | Удалить частично сохранённый файл |
